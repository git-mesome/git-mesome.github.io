I picked up the habit of studying by reading the source code directly, which gave me a deep understanding of how Spring's abstractions are designed. In the process, I went from being a developer who only used other people's code to wanting to design my own libraries. If you're expecting coverage of the latest Spring technologies, this book may fall a bit short, but if you want to build a solid foundation as a developer, it's still a meaningful read.
